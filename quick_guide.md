# Quick reference

Panel: `localhost:7777/control` · Overlay (OBS Browser Source, 1920 × 1080): `localhost:7777/overlay`

Single keys work when you're not typing in a box. Everything can be undone: `Ctrl+Z`.

## Before the case

| To | Do |
| --- | --- |
| Use the London map | **Zones** › London › tick **Used in this case** |
| Name the case | **Case** tab › number, title, date |
| Pick the newspaper | **Paper** tab › **Use** on this case's paper |

## During play

| To | Do |
| --- | --- |
| Record a move | Click the zone (or `/` and type "14 wc") › `Enter` |
| Change the move type | Menu by **Record**: lead, free lead, re-read, dead end |
| Record somewhere off the map | **Off-map lead…** |
| Fix the trail | **Trail** tab › **Edit trail** › change › **Apply** |
| Write a note | `N` › type › `Enter` |
| Pin a note on stream | Start it with `!` |
| Mark a question | Start it with `?` |
| Mention someone or somewhere | `@name`, `#14 WC`, `#scotland` |
| Add a character | `C` |
| Unlock a letter key | `Alt` + the letter |
| Show a clue as a card | **Notes** tab › **Show card** |

## Showing things on stream

| To | Do |
| --- | --- |
| Map | `Ctrl+1` |
| Newspaper | `Ctrl+2` |
| Notes | `Ctrl+3` (or `E`) |
| Directory | `Ctrl+4` |
| Informants | `Ctrl+5` |
| Put the last thing back | The same key again, or `Esc` |
| Zoom the paper onto an article | **Paper** tab › drag a box on the page |
| Look something up | **Documents** tab › search › click a result |
| Show what you found | **Show on stream**; the overlay then follows your preview |
| Hide everything (panic) | `H`, again to show |
| Switch layout | `1` to `9` |

## Map and search keys

| Key | Does |
| --- | --- |
| `/` | Search zones |
| `↑` `↓` › `Enter` | Pick a search result |
| `Esc` | Clear the selection |
| `0` | Fit the map |
| `Ctrl+Shift+Z` | Redo |

## End of case

**Case** tab › fill in scoring (the verdict shows on stream) › **Snapshot PNG** for a recap.
